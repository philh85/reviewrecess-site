Speaking warm-up

Pass the Bomb: a hot-potato speaking game for quick classroom warm-ups

Pass the Bomb is a fast speaking warm-up. Students answer a prompt and pass an object (or the turn) to the next person before the hidden timer goes off. Nobody knows when that will happen, so answers stay short and the room stays focused.

Choose the classic bomb for older students, or a jack-in-the-box, a sleeping bear or a sleeping baby for younger kids. It works with the whole class and needs nothing but your screen and something to pass.

Step by step

How to play Pass the Bomb

Set up the game

  1. Choose a picture style: 💣 Bomb (BOOM!), Jack-in-the-box (POP!), Sleeping bear (ROAR!) or Sleeping baby (WAAH!).
  2. Choose the game mode: Category Mode (the same prompt all round) or Rapid Prompt Mode (a new prompt after every pass).
  3. Set the shortest and longest time. It goes off at a random moment between them, anywhere from 10 to 60 seconds.
  4. Choose your prompts (one per line, or a saved prompt bank), the prompt order and the sound, then press ▶ START GAME.

Play a round

  1. Press ▶ START. The prompt appears in a fixed box above the picture.
  2. The first student answers the prompt and passes the object to the next student.
  3. Press PASS! ▸ after each pass. In Rapid Prompt Mode, the next student gets a new prompt and the clock keeps running.
  4. The picture looks the same the whole time, so nothing gives the end away. Then it goes off: BOOM!, POP!, ROAR! or WAAH!

Scoring and winning

  1. No points are kept. It's a speaking game, and the fun is in not being the one holding it.
  2. The result screen shows the picture, asks "Who was holding the bomb?" (or "Who woke the bear?") and shows the number of passes.
  3. Press NEXT ROUND → to go again, or ⚙ SETUP to change the prompts.

Make it fit your class

Pass the Bomb modes, settings and options

Category Mode

Everyone answers the same prompt until it goes off, for example "Name a mammal".

Rapid Prompt Mode

A new prompt after every pass, for quick-fire review.

Four picture styles

A bomb for older classes, and a jack-in-the-box, a sleeping bear and a sleeping baby for younger kids.

Shortest and longest time

Shortest 10–30 seconds, longest 20–60 seconds. The exact moment is random and hidden.

Prompt order

Random or in order.

Sound on or off

Each style has its own idle sound and ending.

Keyboard

Space to start, → or P to pass, N for a new prompt and X to stop.

Every Review Recess game also has light, dark and high-contrast themes, big text, large buttons and full screen, plus a tick-box question picker and an automatic reshuffle so no question repeats until all have been used.

From the classroom

Tips for teachers

  • Use a soft ball or a beanbag as the object to pass.
  • For younger students, use a longer time range and the jack-in-the-box, bear or baby.
  • In Category Mode, don't count repeated answers. It pushes students to recall more.
  • Use 🎲 New prompt if a category turns out too hard or too easy.

Ideas by subject

Ways to use it across the curriculum

Math

Say a multiple of 5, name a shape, say a number bigger than 100.

ELA

Name a noun, say an action verb, say a word that rhymes with cat.

Science

Name a mammal, name a planet, name something that is a solid.

Social studies

Name a U.S. state, name a continent, name a community helper.

Questions

Pass the Bomb FAQ

Can students tell when it will go off?

No. It goes off at a random moment between your shortest and longest time, and the picture and sound stay the same all round.

Is there a version for younger kids?

Yes. Choose the jack-in-the-box, the sleeping bear or the sleeping baby instead of the bomb.

Does it keep score?

No. It's a speaking warm-up. The result screen shows how many passes there were.

Can I use it for language classes?

Yes. The prompts are yours, and it comes with Quick Review, English ESL and Spanish samples.
